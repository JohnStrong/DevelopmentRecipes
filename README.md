# Recipes

A personal collection of recipes, cookbooks, and reusable patterns for various tools and languages I reach for across my projects. Think of it as a living reference — things I've picked up, refined, and want to remember without digging through old repos or browser history.

## Structure

| Folder | Description |
|--------|-------------|
| `git/` | Handy git commands, configurations, and workflows for managing repos, SSH keys, and multi-account setups. |
